# GAME FACTORY V1

GAME FACTORY는 설치 없이 플레이하는 HTML5 웹게임 플랫폼입니다. 이 저장소는 30개 게임의 초기 출시와 300개까지의 확장을 위해 설계된 정적 우선(Static-first) 플랫폼입니다.

## 현재 단계

- PHASE 01 — Utiqora 구조 분석 완료
- PHASE 02 — 확장 아키텍처 정의 완료
- PHASE 03 — 초기 30개 게임 구현 및 품질 점검 진행 중

## 핵심 원칙

- 모든 게임은 중앙 Game Registry를 통해 사이트에 등록합니다.
- 개별 게임은 독립 모듈로 로드되어 오류·타이머·이벤트 리스너가 서로 영향을 주지 않습니다.
- 게임 상세 URL, SEO 메타데이터, 관련 게임, 사이트맵은 Registry에서 생성합니다.
- 사용자 계정 없이 점수·즐겨찾기·최근 플레이는 브라우저 저장소에서 관리합니다.
- 광고는 게임 조작 영역과 분리된 Safe Ad Zone에만 배치합니다.

자세한 구조는 [아키텍처 문서](docs/architecture.md)를 참고하세요.

공개 준비 상태와 도메인·배포·광고 전 확인 항목은 [출시 체크리스트](docs/launch-checklist.md)에서 관리합니다.
